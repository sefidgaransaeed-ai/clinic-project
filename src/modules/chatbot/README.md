# ماژول chatbot — چت‌بات پرسش‌ها

- **صاحب:** سعید سفیدگران (نفر اول)
- **وظیفه:** چت‌بات پاسخ به پرسش‌های پرتکرار سایت و صفحه پرسش‌های بی‌پاسخ. بدون مدل هوش مصنوعی.

> فقط صاحب این پوشه در آن تغییر می‌دهد. قواعد در `CONTRIBUTING.md` آمده است.

## فایل‌ها

| فایل | چیست |
|---|---|
| `match.ts` | نرمال‌سازی متن فارسی و `matchFaq`. **بدون import از Next یا Supabase** |
| `match.test.ts` | ۲۳ آزمون: املاهای مختلف، ی/ك عربی، نیم‌فاصله، ارقام، پرسش بی‌ربط |
| `data.ts` | خواندن FAQ از سایت، ثبت بی‌پاسخ با تابع سقف‌دار، فهرست صفحه‌بندی‌شده |
| `actions.ts` | Server Action عمومی `ask()` برای ویجت |
| `chat-widget.tsx` | کامپوننت شناور «سؤال دارید؟» |
| `index.ts` | نقطهٔ ورود برای نفر دوم |

## برای خانم مریم (ربات — کار p2-12)

`matchFaq` مستقیم قابل import است و هیچ وابستگی سنگینی ندارد:

```ts
import { matchFaq } from "@/modules/chatbot";

const answers = matchFaq(userMessage, faqRows); // حداکثر ۳، فقط امتیاز بالای آستانه
if (answers.length === 0) {
  // همین‌جا پرسش را با logUnanswered از ./data ثبت کنید، یا از تابع پایگاه داده استفاده کنید
}
```

از `data.ts` import نکنید اگر فقط تطبیق می‌خواهید — آن فایل `server-only` است.

## برای خانم هستی (سایت — چیدمان)

طبق راهنمای p1-15، خودم به `src/modules/site` دست نزدم. برای نشان‌دادن ویجت، در چیدمان سایت:

```tsx
import { ChatWidget } from "@/modules/chatbot/chat-widget";

<ChatWidget phone={siteInfo.phone} clinicName={...} />
```
