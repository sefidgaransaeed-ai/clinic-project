# ثبت تصمیم‌ها

هر تصمیم مهم پروژه اینجا در یک فایل ثبت می‌شود، تا بعداً کسی نپرسد «چرا این‌طوری شد؟» و تصمیم‌های بسته‌شده دوباره باز نشوند.

## چه چیزی اینجا ثبت می‌شود

تصمیمی که **برگرداندنش هزینه دارد** یا **بیش از یک نفر را درگیر می‌کند**: انتخاب فناوری، قاعده کار تیمی، تقسیم مسئولیت، کنارگذاشتن یک راه‌حل.

تصمیم‌های روزمره (نام یک متغیر، رنگ یک دکمه) اینجا ثبت نمی‌شوند.

## نام‌گذاری

`NNNN-عنوان-کوتاه-انگلیسی.md` — مثلاً `0002-public-repo.md`. شماره‌ها پشت سر هم و بدون جای خالی.

## قالب

```markdown
# NNNN — عنوان تصمیم

- **تاریخ:** ۲۸ مهر ۱۴۰۵
- **وضعیت:** تأییدشده | پیشنهاد فنی | باز | جایگزین‌شده با NNNN

## زمینه
چه مسئله‌ای بود؟

## تصمیم
چه چیزی انتخاب شد؟

## دلیل
چرا این و نه گزینه‌های دیگر؟

## پیامد
چه چیزی از این به بعد عوض می‌شود؟ چه چیزی را از دست می‌دهیم؟
```
